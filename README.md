# Why we are here?
I believe that designers, as “outsiders” to coding, do not need to understand programming as a professional developer would. However, we should have a basic understanding of its underlying logic and understand how coding can function within a design project.

One reason designers should learn coding is that, it can become a tool for discovering, expressing, and understanding art. For example, learning to code allows us to understand about something like John Conway’s Game of Life in a more direct way. Coding is not simply a technical skill; it can also become a medium through which we discover new forms of artistic expression. One Chinese phrase I particularly like is “文章本天成，妙手偶得之,” I think new tools often provide precisely these unexpected opportunities for discovery. As Dylan Beattie discusses in The Art of Code, computers have enabled entirely new forms of art, such as “Deep Dreaming.” As technology continues to develop, we will discover more forms of artistic expression that were previously unimaginable.

new tool will provide new inspiration; follow the trend of the times.
